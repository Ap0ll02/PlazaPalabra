# Voice recordings

Drop recordings here as `.ogg` (or `.wav` / `.mp3`), named after the Spanish
text as it appears on screen: lowercase, accents dropped, spaces replaced by
underscores. The listen-and-pick practice exercise (Master tier and up) uses
a clip only if it exists, so recordings can be added a few at a time; with
none present that exercise simply never appears.
